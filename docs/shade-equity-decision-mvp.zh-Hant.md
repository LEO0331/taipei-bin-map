# 樹蔭公平與都市熱環境整備決策支援 v1.0

查核日期：2026-10-20（臺北時間）。方法：`shade-equity-evidence-review-v1`；設定：`1.0.0`。

本模組回答「有限調查量能應優先釐清哪些人行道綠化證據」，不是自動選定種樹位置。目前官方資料可支援盤點及空間關聯檢視，但**人行道長度欄位的量測定義與單位尚未獲得足夠證明，正式快照的合格排序候選為 0**。保留此停止條件，比產出看似完整但無法辯護的熱點排名更適合公共決策。

## 1. 政策問題與適用範圍

適合都市環境、道路及公園管理單位在前期資料整理、跨機關盤點、現勘任務準備時使用。流程為「觀察 → 驗證 → 關聯 → 排序 → 情境 → 查核 → 匯出」。第一個決策是證據是否足以支持下一步，而不是一定要排出名次。

現階段可查閱各區登錄行道樹、人行道及樹穴紀錄，辨識資料未對上的位置及需要補證的原因。不適合直接分配植樹工程經費、認定缺樹責任、評估健康風險或宣稱降溫成效。本系統是獨立研究 POC，並非市府核定計畫。

## 2. 樹蔭公平與行道樹分布的差異

行道樹登錄筆數不等於樹冠面積，樹冠面積也不等於某時段行人的實際遮蔭。樹穴數不等於空穴數；人行道附近有樹，不代表它能遮住行走路線。實際曝熱還涉及時間、日照、風、濕度與使用者停留行為。

因此「分布差異」只能在來源與分母可比較時討論登錄觀察值，不能直接稱為樹蔭不公平。區域均衡情境分配的是調查機會，不是已驗證的環境利益。

## 4. GIS 座標與空間關聯方法

離線處理保留 EPSG:3826（TWD97 二度分帶 121°E）的公尺座標，以 100 公尺網格索引縮小候選集合，再做精確多邊形關係判斷；WGS84 僅供地圖及行政區驗證。未簡化幾何或憑空建立步行路網。

優先使用唯一內含關係；沒有內含時才使用固定 2 公尺近鄰容許距離。碰到邊界、多個可能區段、相反路側或區界問題，不任意猜測歸屬。樹穴另需通過形狀包含檢查，不能只憑代表點認定關聯。一筆唯一配對觀察只計一次；歧義關係保留查核線索但不可加總為不同樹木。

容許距離是分析假設，不是來源定位精度保證；改變距離須重新離線產生受查核快照。圖上的人行道代表點取自原始邊界頂點，只是定位輔助，並非種植建議點。完整規則見[方法文件](shade-equity-methodology.md)。

## 5. 樹木及樹穴盤點品質

行道樹 GIS 接納前排除行政區不符 455 筆、界外或邊界無法確定 21 筆，以及通過前述檢查後的精確重複座標 22 筆。精確共點被保守排除於可加總觀察，並不宣稱現地必為重複樹。接納資料仍有 1 筆缺少有效調查日期、80 筆具非正值等測量旗標；樹高與胸徑單位未確認，未據以推算樹冠。

人行道排除 4 筆無效幾何、2 筆重複幾何、151 筆行政區／界線問題。樹穴排除 174 筆行政區問題。不同階段的「重複數」不是同一指標：原始精確序列重複、標準化幾何重複、通過行政區檢查後的共點數須分開閱讀，不能相互替換。

空間關聯為行道樹唯一配對 45,559、未配對 44,274、歧義 27；樹穴唯一配對 46,109、未配對 480、歧義 4,141。未配對樹可能位於分隔島、其他道路側或缺漏的人行道範圍，不能當成不存在或錯誤樹木；未配對樹穴絕不代表空穴。

## 6. 資料涵蓋與可比較性

資料的更新日期、實際調查日期與本案擷取日期不同。行道樹匯出更新為 2026-10-19，但不表示每棵樹當天受查；人行道與樹穴資源更新為 2026-01-14，個別圖徵缺少調查日期。來源曾更新也不代表涵蓋完整。

目前各區的合格公里分母為未知，跨區標準化比較未開放。區級表格是行政盤點清冊，不是可比較的「每公里樹量」或公平排名。圖徵數、已配對筆數與排除數應一併閱讀；不把部分登錄樹木除以全市推估人行道長度。

## 7. 查核區段與候選定義

查核單元是一個通過幾何查核的官方人行道圖徵，保留原始 ID、行政區、道路、路側及幾何特徵雜湊。相同路名或重複來源 ID 不會直接合併成同一段道路。

「可瀏覽的盤點圖徵」與「可排序的現勘候選」不同：前者目前 14,896 個，後者需再通過來源、行政區、測量定義及情境資格。本快照全部長度保持未知，故候選為 0。不能因 UI 顯示一個位置便視為已通過種植或排序資格。

## 8. 調查優先順序方法

有合格單元時，兩個以上獨立且重大查核問題列 A「優先查核」；一個問題或明確空間歧義列 B「建議查核」；無此類問題列 C「例行盤點」。必要證據不成立則列「證據不足」，不選入名單。

問題必須同時具有不同查核面向及獨立原因；同一來源故障造成多個缺欄，不重複計分。全體都缺樹冠資料、都需確認地下管線，是共通限制而非每段額外加分。排序依等級、獨立問題數、證據信心、固定調查日期（較舊在先、未知在後）、穩定行政區文字與區段 ID 決定，不隨瀏覽當天日期變動。

## 9. 登錄行道樹分布差異

若未來確認相同範圍的觀察母體與有效長度，可計算「唯一配對登錄行道樹觀察／合格人行道公里」。這是行政盤點密度，不是樹蔭比率。分子、分母、排除比例及樣本數必須同時呈現。

目前低登錄量策略停用，也沒有發布「最低 25%」門檻。程式保留通過可比較性後的密度排序能力，不表示已有真實臺北區段的有效低量排名。零配對不能證明零樹，更不能證明高熱風險。

## 10. 查核容量與區域均衡情境

容量代表一次潛在文獻或現地調查，可選 5、10、自訂正整數或不限量。證據優先依查核問題排序；區域均衡則依穩定區域順序輪流抽取，保留各區內原順位。

本案真實快照在全區、固定 2 公尺關聯假設下，證據優先容量 5、容量 10、區域均衡容量 5 都選出 **0 段**。這是相同的空選集，不是「五個地點變十個」或證明區域均衡已達成。增加人力無法補正測量定義；此時應先協調資料供應機關，而非任意指定現勘位置。

## 11. 敏感度分析

容量與策略的比較必須固定來源、地理範圍及候選母體。改變行政區、最短長度、是否納入歧義或來源資格會改變證據範圍，需明示「不同證據範圍」。改變近鄰距離更須重新離線查核，不可只修改畫面參數。

本次已用同一組原始位元組實跑 0／2／5 公尺關聯，匹配樹木分別為 41,830／45,559／47,744 筆；模糊樹木關聯為 0／27／174 筆。樹穴匹配均為 46,109 筆，模糊關聯則為 3,752／4,141／4,200 筆。這只是空間假設改變，不是增加樹木、確認空穴或改善遮蔭；所有情境仍有零個可排序候選。介面及[完整比較檔](../reports/shade-equity/tolerance-sensitivity.json)均明示不同證據範圍。

比較呈現保留、新增、移除及名次變化；選集相同要如實顯示。當前真實資料的長度門檻未開放，嚴格／寬鬆設定不能產生有效排名或熱環境改善證據。非空情境與排序規則由明示合成測試資料驗證，不冒充真實市政結果。

## 12. 現勘問題與種植限制

未來獲得合格查核段後，現勘仍須確認樹／樹穴占用、樹木健康與存活、人行淨寬、地下管線、道路安全及無障礙衝突、土地權責、土壤根域與排水、適合樹種、養護責任及主管機關要求；必要時量測不同時段的行人遮蔭。

這份清單是查核任務，不是已證明存在的現地缺失。既有樹穴可能已有樹、障礙物或無法施工，不能直接將未配對樹穴交付植樹工程。

## 13. 決策摘要與資料匯出

JSON／CSV 的「樹蔭與行道樹整備調查建議摘要」保留政策問題、來源與日期、地理單元、盤點觀察、關聯與排除、方法、容量、選取理由、情境比較、品質疑慮、現勘問題及不支持的推論。即使候選為空，也應保留情境摘要及版本，避免空檔被誤解為零需求。

CSV 對可能觸發試算表公式的文字做防護；不匯出虛構樹冠、溫度、空穴數或正式種植許可。本模組使用官方設施紀錄，不蒐集使用者帳號、個人行蹤或新增個資調查。

## 14. 數據版本及可重現性

原始來源快照為 `shade-source-v1-078b91443dc33e45`，衍生快照為 `shade-equity-v1-8e4cfb4029d0831d`，處理事件時間為 `2026-10-20T00:41:41.554Z`。每個來源保留 SHA256、資源 ID、擷取與資源更新日期；不同日期不互相覆蓋。

大型原始檔以無損 gzip 保存，還原時驗證解壓後原始位元組，避免官方可變下載端點破壞歷史重現。新下載成功不等於採用；識別或雜湊改變須另建審查版本。重現命令及完整規則見[方法文件](shade-equity-methodology.md)；不可順便刷新既有垃圾桶政策資料。

## 15. 工程架構與測試結果

來源資訊採單欄手風琴列表，一次展開一個來源。收合列保留來源名稱、適用性與更新日期；識別碼、座標系統及 SHA256 放入第二層「技術資訊」，提供完整值複製。瀏覽器不支援剪貼簿或拒絕存取時，保留可選取文字與手動複製提示；不因此改動來源日期、品質判讀或分析門檻。

使用既有 Vite／React／TypeScript 與雜湊路由 `#/shade-equity`，模組與資料延遲載入。官方來源在離線 Node／TypeScript 管線中完成驗證與空間關聯；瀏覽器不直接呼叫臺北開放資料，亦不需新後端、GIS 付費 API 或 UI 框架。列表優先、限制地圖渲染量並提供文字表格，避免把全部原始幾何逐次送入瀏覽器情境。

既有垃圾桶 Mode A／B 的演算法、核准快照及治理門檻保持獨立。新測試涵蓋來源契約、幾何、獨立問題、資格、容量、情境範圍及匯出；真實零候選與合成非空案例分開驗證。基線為 308 項測試、142 項 E2E 及 production build；本次最終實測數與桌機／手機紀錄以[交付驗證文件](shade-equity-delivery.md)為準，不將基線冒充新增後結果。

## 16. 不支持的樹冠、遮蔭及熱風險推論

本案不發布實測遮蔭率、缺蔭確診、氣溫下降、健康風險分數、樹木死亡預測、空穴容量或核定種植地。未以物種／樹高／胸徑合成冠幅；未將測站氣溫、全市平均、衛星地表溫度當成街段行人體感；未將年度存量差或缺少 ID 當作砍樹事件。

地圖沒有根據樹點製造的熱圖、人工樹冠多邊形或虛構工程位置。公共政策敘事可用來形成研究問題，不能取代逐筆證據。

## 17. 後續擴充與資料需求

第一優先是取得出口欄位對應的長度／淨寬定義、個別調查日期、完整涵蓋範圍及路側關係，處理重疊、界線與未配對觀察，再決定是否發布可比較區域或受查核試辦區。不能把試辦區結果當作全市結果。

下一階段才考慮帶日期與精度的樹冠量測、可重現的行人遮蔭觀測、區段尺度熱曝露研究、樹穴現勘占用、管線及根域／權責資料。各來源須獨立建立品質與採用門檻。對決策者最有用的近期輸出是「還缺哪項證據、由誰補、補完才能決定什麼」，而不是在證據不足時仍產生漂亮排名。
